# 🚗 Auto Price Prediction

## 📌 Overview  
This project applies **data science techniques** to analyze automobile datasets and predict car prices using multiple machine learning models. The objective is to provide management and stakeholders with actionable insights into the factors influencing pricing, while also delivering a reliable predictive framework for decision-making.

---

## 📊 Data Analysis  
- Performed **data cleaning and preprocessing** to handle missing values and inconsistencies.  
- Conducted **exploratory data analysis (EDA)** with descriptive statistics and visualizations.  
- Used scatter plots, box plots, and correlation heatmaps to highlight relationships between features such as engine size, horsepower, mileage, and fuel type.  
- Identified key variables that strongly impact car prices.  

---

## 🤖 Predictive Modeling  
The following models were implemented and evaluated:  
- **Linear Regression**  
- **Random Forest Regressor** (n_estimators=100, random_state=42)  
- **Gradient Boosting Regressor** (n_estimators=100, random_state=42)  

### 📈 Evaluation Metrics  
Each model was assessed using:  
- **RMSE (Root Mean Squared Error)**  
- **MAE (Mean Absolute Error)**  
- **R² (Coefficient of Determination)**  
- **Cross-Validation Mean R²**  

This combination of metrics ensures robust evaluation, balancing accuracy, error minimization, and generalization capability.

---

## 🛠 Tech Stack  
- **Python**: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn  
- **Jupyter Notebook / VS Code** for experimentation  

---

## 🎯 Outcomes  
- Comparative performance analysis of three regression models.  
- Identification of the most influential variables affecting car prices.  
- A reproducible workflow covering preprocessing, EDA, model training, and evaluation.  
- A predictive model that supports **data-driven pricing strategies**.  

---

## 🌟 Significance  
This project demonstrates the **end-to-end data science pipeline** in a real-world context. By combining statistical analysis with machine learning, it bridges the gap between raw data and actionable insights. It serves as a valuable resource for learners, practitioners, and organizations aiming to understand how modern data-driven approaches can transform traditional pricing models in the automotive industry.
